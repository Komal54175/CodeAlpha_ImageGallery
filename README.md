# Image Gallery

A responsive image gallery built as part of my **CodeAlpha Web Development Internship** (Task 1).

## Features
- Image gallery grid layout using HTML and CSS
- Lightbox view with next / previous navigation using JavaScript
- Hover effects and smooth transitions
- Fully responsive for different screen sizes
- Image filters / categories

## Technologies Used
- HTML5
- CSS3
- JavaScript

## How to Run Locally
1. Clone the repository:
   ```
   git clone https://github.com/Komal54175/CodeAlpha_ImageGallery.git
   ```
2. Open `index.html` in your browser.
